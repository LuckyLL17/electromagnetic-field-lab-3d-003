# ElectroMag Lab · 3D

基于 React、Vite、TypeScript、Three.js 与 React Three Fiber 的专业 3D 可视化实验平台。

## 启动

```bash
npm install
npm run dev
```

开发端口：`5176`。

## 测试

```bash
npm test
```

使用 TypeScript 编译到临时目录后交由 Node 内置测试运行器（`node --test`）执行，
无需额外测试框架。覆盖三维测量剖面的拖动几何、场型/强度切换后的世界坐标
恒定性、高密度采样的分块取消/中断恢复、过期结果丢弃、LRU 缓存与无效位置处理。

## 三维测量剖面（3D Measurement Probe）

场景内置一个可拖动的三维测量剖面（紫色半透明平面）：

- **世界坐标锚定**：剖面中心、法向与平面基向量全部以世界坐标表达。场源模型
  位于带固定旋转的 group 中，采样时通过该旋转把世界点变换到模型坐标求值，
  场矢量再旋回世界坐标。因此切换场型（电偶极子 / 螺线管 / 平行板电容器）、
  调节激励强度或旋转相机，剖面始终表示同一物理位置。
- **拖动**：在平面上按下并拖动，剖面严格沿其世界法向（X / Y / Z 可选）
  平移；拖动期间自动禁用 OrbitControls。相机视线与法向近乎平行等无效
  情形会被忽略。
- **右侧面板**：展示剖面的二维采样热力图（可点击选点、右键清除）、
  最大 / 平均场强、选点处的世界坐标、场矢量、与法向夹角及文字化的
  方向描述（如「+X、偏 −Z」），并提供尺寸与高密度采样密度调节。

### 实时重算与缓存的取舍

采样调度（`src/field/probeCore.ts` 中的 `SamplingController`）：

- **拖动中**：同步计算 ≤28×28 的低分辨率实时结果，保证画面跟手；
  实时结果不写入缓存。
- **停止 / 改参后**：140ms 防抖，再以分块（每 8 行让出一次事件循环）
  方式异步计算高密度结果，完成后写入 LRU 缓存（默认 64 条）。
- **取消与过期**：任何新请求都会令上一个分块任务代数作废；组件卸载
  或重新拖动时取消在途任务，过期结果即使晚算完也不会更新界面。
- **无效输入**：NaN / Infinity 位置与非法尺寸抛错并进入 `invalid` 状态；
  极大但有限的坐标会在矩阵变换前钳制，避免溢出为 NaN；越界位置钳制在
  场域内。

## 目录

- `src/field/probeCore.ts`：纯逻辑（平面基向量、世界↔场坐标、场模型、
  采样、拖动/选点射线数学、分块采样调度器与 LRU 缓存），无 React / DOM
  依赖，可直接单元测试。
- `src/field/useProbeSampling.ts`：实时/防抖最终结果的 React 编排 hook。
- `src/field/heatmap.ts`：二维热力图与色标的 canvas 绘制。
- `src/field/Probe3D.tsx`：三维可拖动平面、热力图纹理与选点矢量箭头。
- `src/field/ProbePanel.tsx`：右侧测量面板。

项目仅实现前端基础实验流程，后续可扩展真实 CFD / FEM 数据导入、网格解析、更多测量工具和实验结果导出。
